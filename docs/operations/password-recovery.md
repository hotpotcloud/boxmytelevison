# 账号密码修改与忘记密码恢复

## 记得当前密码
登录网站 → 个人账号 → 登录与安全 → 输入当前密码和两次新密码 → 更新密码。修改后所有设备需要重新登录。

## 忘记密码（服务器管理员）
登录服务器 SSH 终端，执行以下命令。新密码由工具隐藏输入两次，不写进命令、命令历史或日志。不要直接修改 password_hash 字段。

```bash
release_dir=$(systemctl show boxmytelevison -p WorkingDirectory --value)
node_bin=$(sudo cat "$release_dir/.node-path")
sudo "$node_bin" "$release_dir/reset-password.cjs" xbf
```

按提示输入新密码两次（8–128 字符），出现成功提示后直接使用新密码登录，无需重启服务。

重置普通注册账号时，把最后的 xbf 换成该账号注册邮箱。工具仅修改匹配账号的密码哈希并撤销其所有会话；账号角色、注册信息、个人源和其他账号不变。账号不存在、两次密码不一致或密码过短均不会修改数据。

数据库默认 /opt/boxmytelevison/data/accounts.sqlite；自定义部署可以通过 --database 绝对路径指定现有数据库。工具不会创建账号或数据库。仅有服务器权限的管理员能运行此工具，不提供免身份验证的公开重置接口。

管理员初始密码仅首次部署创建账号时使用；修改 GitHub 初始化密码变量或重新部署不会覆盖现有账号的新密码。

## 普通用户
忘记密码时联系站点管理员。邮箱目前未验证，不能仅凭邮箱地址自助修改密码；不需要购买短信或邮件 API 来使用服务器恢复工具。
