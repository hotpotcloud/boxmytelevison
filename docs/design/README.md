## 设计依据

用户要求：整体布局与交互大改版，iOS/macOS 风格，浅色和深色可切换，分组与分页，可以引入轻量组件库。普通用户邮箱注册，暂不发验证码；另设独立管理员账号。密码不进入设计稿或版本库。

## 提案

桌面端采用左侧分组导航，分为“浏览”和“我的”，底部集中源管理与设置。顶部保留全局搜索、外观切换与账号入口。内容区为精选推荐、分类筛选与影片网格；网格采用明确分页和每页数量选择。

移动端使用两列海报、分类分段控件与底部导航，不挤压桌面侧栏。两种主题保留同样的功能、层级和操作位置。

## 评审边界

海报、评分、影片标题与数量均为视觉示例，不代表当前数据源可提供这些内容。影片详情、播放、收藏等操作实现时要接入真实数据，不能保留无行为按钮。地区、年份、类型与排序的可用范围需按推荐 API 和搜索结果字段确定；数据不支持的筛选不能伪造。

“我的收藏”是新增功能，需独立实现与验证；本轮账号持久化不等于观看历史或收藏已经支持云同步。图片中的 macOS 窗口装饰不作为网页控件实现。
