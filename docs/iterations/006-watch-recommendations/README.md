# 006 · 播放页推荐与移动端适配

## 需求与执行标准

- 桌面播放页右侧保留当前影片选集，增加其他影片的推荐，禁止用剧集充当其他影片。
- 根据详情中的类型与地区选择电影、国产剧、海外剧、综艺、动画或纪录片推荐；类型缺失使用电影榜单。此版本为规则推荐，不收集观看行为，不宣称个性化推荐。
- “热门发现”提供独立的热门电影入口；推荐池最多 24 部，每批显示 6 部，支持换一批。
- 统一 Unicode、空白与标点后排除当前片名和重复片名。推荐点击进入站内搜索，由用户选择可用源，不编造播放地址或可用状态。
- 推荐请求独立于播放器与选集，缓存十分钟，取消请求随组件生命周期处理。主数据源失败或为空时使用备用数据源，全部失败时提供重试及首页入口。
- 不新增数据库表、依赖、后台定时任务或 Docker，沿用既有服务端缓存接口与服务器安装依赖的发布方式。

## 布局与交互标准

- 保留 iOS/macOS 风格及浅色、深色主题，沿用既有 PosterCard 和图片加载降级。
- 桌面：右侧依次为选集、推荐，播放器宽度不减少。长选集最多占 240px，推荐网格最多占 520px 并在内部滚动，避免整页被侧栏拉长。
- 手机：内容依次排列，推荐双列，增加“发现更多影片”直达入口；平板推荐三列；影院模式宽屏六列。
- 推荐切换、换一批、收藏与手机直达入口触控区域至少 44px；加载、失败、空列表有明确状态。
- 推荐不会自动播放或批量探测媒体；游客可浏览推荐，收藏仍遵守现有登录规则。

## 已知边界

推荐来自现有热榜与豆瓣接口，第三方可能限流或不可用，不能保证每部推荐都在点播源中可搜索。动画或纪录片接口失败回退通用榜单时，界面会显示“热门榜单”。当前标题按格式归一后进行精确排除，不推断续集或翻拍片的关联。
