# 005 · 默认点播源扩充

## 需求与标准
先验证，再添加。测试从腾讯云应用实际所在网络发起，不以本机连通或 HTTP 200 作为可播放证据。只接入通用 JSON 搜索与详情、HLS 清单/密钥/分片可读，且播放器能输出画面的源。测试并发 2；视频分片只抽取 64 KiB；浏览器关闭预取，控制服务器流量与内存。

## 配置策略
只向 deploy/server.env 的 DEFAULT_SOURCES 追加，保留原前 6 条及顺序，确保 env_0–env_5 和已有分享链接不变。新增 env_6–env_10，保留用户取消勾选的意图；新源首次出现按现有规则自动可选。不修改账号个人源、直播源、密码或数据库。

## 复查命令
```bash
node scripts/check-vod-sources.cjs --input docs/iterations/005-vod-sources/candidates.json --output vod-source-results.json
```

可用 --base 指向其他部署。该脚本只通过现有公开搜索、详情、播放接口发起读取，不新增探测权限，不修改站点配置。
