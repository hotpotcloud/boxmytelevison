# 004 · 忘记密码恢复

- [x] 保留已有的当前密码修改功能。
- [x] 登录弹窗和登录与安全页面增加忘记密码说明与管理员恢复指南。
- [x] 随发布携带零依赖服务器重置工具，隐藏输入新密码并二次确认。
- [x] 验证新密码可登录、旧密码失效、全部会话撤销、个人源与其他账号不变。
- [x] 类型检查、Lint、构建、CI 与公网入口验收。

执行标准：仅服务器终端可恢复；不接受命令行密码、管道、未经验证的邮箱自助重置；scrypt 哈希与线上账号一致；数据库不存在或账号不唯一时拒绝；事务更新并撤销会话；不得重置生产真实账号做测试。

[运维使用指南](../../operations/password-recovery.md)

本地验证：42 个测试文件、499 项测试通过；类型检查、Lint、生产构建通过。包含管理员恢复后重新打开数据库仍保留新密码、拒绝无效账号/短密码/不存在数据库/管道输入。部署验证使用随机临时账号，检查恢复登录、旧密码拒绝、会话撤销、个人源保留后自动删除该账号。
