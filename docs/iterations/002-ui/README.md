## 视觉标准

1. 桌面基准 1440×960，侧栏宽 216px，内容最大宽 1440px，内容区 32px 留白；平板缩小留白，低于 1024px 切手机导航。
2. 页面灰白 / 石墨背景，蓝色主操作，语义 token 管理亮暗两套颜色；不采用霓虹和品牌渐变。
3. 使用系统中文和 Apple 平台字体栈；正文 14–16px，标题 26–32px；触控操作目标至少 44px。必要的卡片辅助信息可为 12px。
4. 推荐网格手机 2 列、平板 3–4 列、桌面最多 6 列；海报固定 2:3，比率不随图片改变。
5. 原生磨砂效果仅用于导航和浮层，动画限制为短暂 opacity/transform，遵守 prefers-reduced-motion。
6. 不实现设计稿中的伪 macOS 窗口按钮。所有网页控件必须有真实行为和可访问名称。

## 数据和交互标准

1. 精选 / 海报来自现有真实推荐接口；“查看片源”先发起搜索，不承诺推荐影片一定可直接播放。
2. 推荐 API 没有地区 / 年份字段，不提供虚假过滤。推荐按真实分类、评分或标题排序；搜索才使用真实地区 / 年份 / 类型字段。
3. 每页支持 12 / 24 / 48 项，切换分类、过滤或每页数量后回第 1 页。只有一页时也显示总量和页状态；边界按钮禁用。
4. 分类在 URL 中可表达，浏览器前进后退恢复分类。流式搜索新增结果不应强制跳回第 1 页。
5. 加载用等比例骨架屏，失败给重试，空数据给明确原因。无登录状态不重复请求受保护推荐接口。
6. 收藏按本机 IndexedDB 保存，明确提示数据范围；条目可移除，点击能重新搜索片源。
7. 账号会话 Cookie 不放 localStorage，菜单退出必须撤销服务器会话；表单错误保留在弹窗中。
8. Radix 负责账号弹窗焦点管理和账号菜单键盘交互；Tab 焦点、Esc、点击外侧行为要验证。
