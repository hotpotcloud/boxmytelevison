# 003 · 幕间 Muu：游客、播放工作区与账号源同步

## 已确认需求
- 品牌：幕间 · Muu，iOS/macOS 风格，保留亮色/深色/跟随系统。
- 游客无需访问密码即可发现、搜索、点播、直播；不保存搜索、观看历史、进度或最近频道；不能收藏。
- 收紧侧栏空隙，首页增加真实内容，每页默认 24，可选 12/24/48。
- /watch 与首页同步改版：利用宽屏，播放器和选集并排，40 集分组、影院布局与移动端单列。
- 站点统一下发默认源；注册用户新增/修改/删除源与启用状态保存到账号，换设备恢复。

## 执行与验收标准
1. 媒体 API 使用明确的路径和方法白名单开放；账号配置和密码变更必须校验真实账号会话。发布与批量探测保留原认证。
2. 游客播放超过 2 秒、触发进度回调后，IndexedDB history/progress/searchHistory 不增加；旧记录不向游客展示，不删除登录用户记录。
3. 个人源使用现有 SQLite user_source_profiles 表，按 user_id 隔离，外键级联删除。默认源正文不写入个人源表。
4. GET/PUT /api/account/sources 仅返回当前账号；PUT 同源、JSON、256 KiB 上限、条数和字段校验；版本冲突返回 409，禁止静默覆盖。
5. 登录恢复云端个人源，退出恢复独立游客配置；不同账号缓存分开。断网保留待同步本机配置，显式重试；冲突可先导出，再确认载入云端。
6. 桌面 1440/1920、平板 1024、手机 375/390，无横向溢出；播放器不再受旧 1280px 页面上限限制。选集按钮至少 44px。
7. 保留换源、下载、自动连播、键盘操作、主题切换；不伪造封面、评分、视频或片单数量。
8. 类型检查、Lint、单元/接口测试和生产构建通过；独立浏览器验证游客、账号隔离、跨设备同步与播放布局。
9. 部署继续采用 systemd + Node 22，应用小包上传，服务器从镜像安装生产依赖；不使用 Docker、不上传完整依赖。

## 边界
历史和收藏仍保存在当前浏览器；本轮跨设备同步范围为个人源（点播源、直播源、订阅与勾选状态）。注册邮箱尚未验证，不引入付费邮件接口。保留 LibreTV 开源许可证和上游归属。

## 本地验收结果
- 40 个测试文件、493 项测试通过，类型检查、Lint、生产构建通过。
- 独立 Edge 验证：游客零历史/零进度/零搜索记录/零收藏；实际公开测试流播放超过 2 秒，1920×1080 画面输出，无页面异常。
- 1440px 播放器宽 1034px；1920px 宽 1474px；375/390px 无横向溢出，90 集测试数据可分为 1–40、41–80、81–90。
- 两个独立浏览器上下文恢复同一账号个人源；其他账号为空；冲突在刷新后仍阻止覆盖；退出后不显示个人源。
- 首页先显示 100 部热门影片，随后补入去重周榜（初次测试共 141 部，数量随真实数据变化）；默认每页 24。
- 点播与直播代理均匿名返回有效 HLS，私网目标分别被 400/403 拒绝。批量探测与发布继续需要认证。
